🐙 GitHub 本周热门项目

Agent

n8n-io/nod

n8n 出的开源个人 agent，自带一台"电脑"：能追发票、准备通话、在真实网站上取消试用订阅，动手前会先征求同意，模型可自选。

Agent

backnotprop/plannotator

和 agent 协作的工作台：规划、决策、给代码做标注和审查，再把反馈一键发回给 agent。

工具

alibaba/open-code-review

阿里开源的代码审查工具，在阿里内部规模验证过：确定性流水线 + LLM Agent，给出行级评论，内置多语言规则（空指针、线程安全、XSS、SQL 注入）。

MCP

ChromeDevTools/chrome-devtools-mcp

给编程 agent 用的 Chrome DevTools MCP，让 agent 能直接调试网页。

Skills

google-labs-code/stitch-skills

Google Labs 的 Agent Skills 库，配合 Stitch MCP 使用，遵循开放标准，兼容 Claude Code、Cursor、Gemini CLI 等编程 agent。

协议

ag-ui-protocol/ag-ui

AG-UI：Agent 与用户界面的交互协议，把 agent 接进前端应用的标准方式。
